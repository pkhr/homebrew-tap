# pkhr/homebrew-tap

Personal Homebrew tap.

## Install

Install by full name: that also tells Homebrew to trust this formula or cask
([Tap Trust](https://docs.brew.sh/Tap-Trust)).

```sh
brew install pkhr/tap/<formula>
brew install --cask pkhr/tap/<cask>
```

## Formulas

| Name | Description |
| --- | --- |
| [acwake](https://github.com/pkhr/acwake) | macOS launchd daemon to stay awake on AC, sleep on battery |

## Casks

| Name | Description |
| --- | --- |
| [mf4700-print-scan](https://github.com/pkhr/mf4700-print-scan) | Canon MF4780w Print & Scan: driverless printing and scanning for Canon MF4700-series printers |

The Canon MF4780w Print & Scan app is not notarized by Apple, so macOS blocks its
first launch: open it once, then click **Open Anyway** in System Settings >
Privacy & Security.
